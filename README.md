# 两室一厅装修设计器

基于一张彩色位图户型图毫米级还原的可交互装修设计方案，输出为**单文件 HTML**，双击即可在浏览器离线打开，无需联网、无需安装任何依赖（原始户型底图已内嵌）。

## 在线预览

GitHub Pages 在线站点（打开即用）：<https://lemonflyliu.github.io/house-plan-designer/>

也可以 clone 本仓库后双击 `index.html` 在浏览器离线打开。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主交付物，单文件交互式设计器（约 1.5 MB，底图已内嵌，同时是 GitHub Pages 站点入口） |
| `户型图.png` | 原始户型底图 |
| `平面布置图.png` | 2D 彩色平面布置预览 |
| `三维鸟瞰图.png` | 3D 鸟瞰预览 |
| `spec.json` | 户型结构化数据（HouseSpec） |
| `gen.py` | 由像素测量结果生成 `spec.json` 的脚本（依赖 house-plan-designer 工具链的 `axismap` 模块） |

## 设计器功能

- 2D 平面 / 3D 鸟瞰 / 第一人称漫游，720° 全景与渲染出图
- 点选家具、墙、门窗直接拖拽，点击蓝色尺寸可输入精确数值
- 水电（已自动布点）、吊顶、铺装、拆改图层切换
- 自动报价、日照模拟、导出 PDF / DXF 与彩平图
- 可叠加原始底图对照，一键恢复初始户型

## 已知建模偏差

1. 次卧飘窗采用标准凸窗构件（凸出约 380–520 mm），浅于原图净深约 660 mm，故次卧模型面积偏小；飘窗垫可在设计器内自行添加。
2. 原图墙体同色，承重墙按厚度推断（240 mm 为承重、120 mm 隔墙非承重），实际拆改请以物业结构图为准。
3. 厨房、卫生间按原图实墙还原为无外窗的暗厨暗卫；阳台经厨房推拉门进入，南墙为实墙。
4. 入户门按双开门还原，家具为按动线给出的默认布置，均可在设计器内自由调整。
